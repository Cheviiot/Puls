# История изменений

Значимые изменения Puls будут перечисляться в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [0.3.2] - 2026-09-05

### Исправлено

- Release workflow преобразует создаваемый Fyne Android App Bundle в
  подписанный universal APK через проверенный `bundletool` и проверяет его
  доступными в Android Build Tools утилитами.
- Полный ручной preflight собирает и проверяет все артефакты без публикации
  тега или GitHub Release.

## [0.3.1] - 2026-09-05

### Исправлено

- Release workflow устанавливает проверенный по SHA-256 `bundletool`, необходимый
  Fyne для сборки и подписи Android APK.

## [0.3.0] - 2026-09-05

### Добавлено

- Команда `puls gui` с единым адаптивным Fyne-интерфейсом, системной, светлой
  и тёмной темами.
- Android-приложение с теми же измерениями и подписанный APK в GitHub Releases.
- Ярлыки GUI для Linux, macOS и Windows; их можно отключить параметром
  `--no-shortcut` / `-NoShortcut`.

### Изменено

- CLI и GUI используют общий `internal/application.Runner`; сетевые алгоритмы
  и JSON schema 1 не изменены.
- Release manifest обновлён до schema 2 и указывает тип и возможности каждого
  asset. Desktop GUI собирается нативно; Windows arm64 пока остаётся CLI-only.
- Установщики создают и удаляют только управляемые ими ярлыки. Повторный запуск
  по-прежнему обновляет Puls до последнего стабильного релиза.

### Приватность

- GUI сохраняет только настройки интерфейса и измерения. IP, ISP, результаты,
  серверы, diagnostics и временные credentials не записываются на диск.

## [0.2.0] - 2026-09-04

### Изменено

- Release candidate `v0.2.0-rc.1` принят без изменений публичного CLI, JSON и
  сетевых протоколов.

## [0.2.0-rc.1] - 2026-09-04

### Добавлено

- Команда `puls ip [speedtest|yandex]`: speedtest.ru возвращает внешний IP и
  интернет-провайдера, при автоматическом выборе доступен fallback на Яндекс.
- Единый JSON envelope schema 1 с верхнеуровневым `connection`, массивом
  `results`, объектами фаз и типизированными ошибками.
- Определение IP через first-party API speedtest.ru с одной ротацией browser
  key после 401/403; ISP остаётся необязательным дополнением.
- Адаптивный TTY progress и отдельные diagnostics в `stderr`.

### Изменено

- Пользовательский термин «источник» заменён на «сервис измерения», конкретный
  CDN/QMS называется «сервером измерения», оператор — «интернет-провайдером».
- Внутренний пакет `internal/provider` переименован в `internal/service`, а
  контракт `Provider` — в `Backend`.
- CLI разделён на parsing, configuration, orchestration, connection info,
  results, JSON и rendering; реализации сервисов и release builder также
  разбиты по зонам ответственности.
- Общие HTTP limits, strict JSON, connection limits, progress conversion и
  преобразование engine results централизованы.
- Ошибки классифицируются по типам, sentinel errors, `context` и `net.Error`,
  без анализа текста.

### Удалено

- Устаревшие flags `--ip` и `-ip`; им на смену пришла команда `puls ip`.
- JSON v0.1 с верхнеуровневым полем `provider` и отдельными форматами single/all.

### Совместимость

- Миграция v0.1 → v0.2: `puls --ip` заменить на `puls ip`, JSON-поле
  `provider` — на `results[].service`, данные подключения читать из
  `connection`. Остальные публичные English flags сохранены.

## [0.1.5] - 2026-09-03

### Добавлено

- Параметр `--ip` (доступен и как `-ip`) — отдельная быстрая команда, которая
  печатает только внешний IP через Яндекс.Интернетометр и завершает работу,
  без выбора сервера и измерения задержки/скорости. В отличие от `--show-ip`
  (дополняет обычный замер), `--ip` не запускает измерение вовсе. Доступен
  только для `yandex`; для `speedtest` и `all` возвращает usage error.

## [0.1.4] - 2026-09-03

### Добавлено

- Параметр `--show-ip` показывает внешний IP-адрес, определяемый через
  главную страницу Яндекс.Интернетометра. Доступен только для источника
  `yandex`; для `speedtest` строка отображается как «не поддерживается», а
  JSON-поле `external_ip` — `null`. Отказ определения IP не влияет на
  результат измерения и код завершения.

## [0.1.3] - 2026-09-03

### Исправлено

- На Windows classic-консоль (`conhost.exe`, используемый Windows PowerShell и
  cmd.exe) теперь получает `ENABLE_VIRTUAL_TERMINAL_PROCESSING` при старте, до
  этого цвета и управляющие последовательности интерактивного меню выводились
  как сырой текст (`←[1m`, `←[36m` и т.д.) вместо форматирования.

## [0.1.2] - 2026-09-02

### Исправлено

- Установщики Linux, macOS и Windows выбирают пакет строго по OS и architecture
  из `RELEASE_MANIFEST.json`, сверяют его digest с `SHA256SUMS.txt` и проверяют
  контрольные суммы manifest и архива до распаковки.
- Unix-установщик без явного override всегда использует `$HOME/.local/bin`, а
  Windows-установщик — `%LOCALAPPDATA%\Programs\Puls\bin`.
- Unix-установщик извлекает из архива только ожидаемый обычный файл `puls`.
- Исходник Windows-установщика сделан ASCII-безопасным, а русские сообщения
  декодируются из UTF-8 во время выполнения. Поэтому `irm ... | iex` и прямой
  запуск файла работают в Windows PowerShell 5 независимо от системной кодовой
  страницы.

## [0.1.1] - 2026-09-02

### Изменено

- Unix-установщик автоматически и идемпотентно настраивает `PATH` для Bash,
  Zsh, Fish и других POSIX-оболочек; удаление очищает только созданную Puls
  запись.
- Повторный запуск установщика явно обновляет существующий binary и не
  дублирует конфигурацию окружения.

## [0.1.0] - 2026-09-02

### Добавлено

- Измерение задержки, скорости скачивания и отдачи через Яндекс.Интернетометр.
- Измерение через speedtest.ru с выбором сервера и обновлением авторизации.
- Русскоязычный интерфейс со стандартным английским синтаксисом CLI.
- Структурированный JSON, частичные результаты и корректные коды завершения.
- Кроссплатформенные архивы для Linux, Windows и macOS.
- Автоматические проверки и выпуск релизов через GitHub Actions.
- Лицензия MIT.
- Новая публичная документация с быстрым стартом, примерами, расходом трафика и процедурой обновления протоколов.
- Репозиторные инструкции для AI-разработчиков.
- Прямая установка из GitHub Releases для Linux, macOS и Windows без отдельных package repositories.
- Проверяющие SHA-256 установщики `install.sh` и `install.ps1`.
- Штатное удаление через `install.sh --uninstall` и `install.ps1 -Uninstall`.
- Машиночитаемый `RELEASE_MANIFEST.json` с целями и SHA-256 релизных архивов.
- Самодостаточные release archives со всей публичной Markdown-документацией и checksummed installer assets.
- Документация архитектуры, поддержки и поведения участников.
- Автоматические release notes и provenance attestation релизных артефактов.
- Integration tests прямой установки и удаления на Linux, macOS и Windows.

### Изменено

- Усилена проверка discovery, HTTP-ответов и WebSocket-сообщений Яндекса и speedtest.ru.
- Обновлён общий движок измерений: корректная отмена, ранний отказ всех потоков, одно переподключение и освобождение goroutine.
- Релизный workflow теперь запускает форматирование, race detector, vet, staticcheck и govulncheck, готовит проверяемый draft и только затем публикует release.
- Release builder добавляет оба установщика в `SHA256SUMS.txt` и provenance attestation.
- Подробные инженерные документы перенесены из корня в каталог `docs`.
- Community-файлы GitHub перенесены в `.github`, исходники установщиков — в `scripts`.
- README сокращён до быстрого старта и основного контракта; дублирующие документы удалены.

### Исправлено

- Download учитывает полученные байты потоково после полной проверки HTTP-заголовков и сохраняет явную ошибку при повреждённом ответе.
- Сетевые ошибки не отображаются как успешные нулевые скорость или время измерения.
- Резервный список speedtest.ru используется только для ping; без JWT throughput возвращает явную ошибку авторизации.
