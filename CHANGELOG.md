## [0.1.0] - 2026-10-01

Первый выпуск Puls на C++. Нумерация версий начата заново: выпуски
0.1.0–0.3.3 на Go удалены. Puls 0.1.0 устанавливается поверх них той же
командой установки, а APK обновляет установленное Android-приложение.

### Добавлено

- Реализация на C++20: CLI, application runner, engine и протоколы
  Яндекс.Интернетометра и speedtest.ru собираются CMake и vcpkg. Команды,
  флаги, JSON schema 1 и коды завершения прежние.
- Workflow `C++` собирает и тестирует Linux GCC/Clang, ASan+UBSan, TSan,
  macOS и Windows MSVC и проверяет форматирование.
- Графический интерфейс на Qt 6 Quick (QML) вместо Fyne: тот же mobile-first
  dashboard, системная, светлая и тёмная темы, настройки измерения и
  определение подключения. Сохраняются только тема, параметры измерения и
  размер окна.
- Графический интерфейс — отдельная программа `puls-gui` (на macOS —
  `Puls.app`), которую запускает `puls gui`. CLI не зависит от Qt и
  графических библиотек и работает на серверах без графического окружения.
- Зависимости, включая Qt, линкуются статически, на Windows вместе с CRT, и
  программы собираются для Linux, macOS и Windows на x64 и ARM64 (на Windows
  ARM64 — только CLI). Программам для Linux нужна только glibc 2.28.
- Android-приложение собирается с Qt for Android: один APK для arm64-v8a,
  armeabi-v7a и x86_64, Android 9 и новее. Application ID и ключ подписи
  прежние, поэтому APK обновляет установленное приложение.

### Изменено

- Выпуск собирают workflow `C++` и `scripts/release.py`: архивы содержат
  `puls` и `puls-gui` (на macOS — `Puls.app`) и лицензии зависимостей,
  `RELEASE_MANIFEST.json` получает schema 3. Установщики ставят обе программы
  и принимают только schema 3. На Linux установщик называет системные
  библиотеки, которых не хватает графическому интерфейсу. Выпуск публикуется
  тегом версии или запуском workflow Release на `main` с отметкой `publish`.
- Ошибки флагов, которые прежние версии показывали по-английски, — неверный
  синтаксис и неверное логическое значение — выводятся по-русски.
- Android-приложению нужен Android 9 или новее (прежде — Android 5): этого
  требует Qt 6. На Android 5–8 новая версия не устанавливается, а
  установленная прежняя продолжает работать.

### Удалено

- Реализация на Go, включая GUI на Fyne, Go release builder и Go CI.
