# История изменений

Значимые изменения Puls будут перечисляться в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [0.1.2] - 2026-09-02

### Исправлено

- Установщики Linux, macOS и Windows выбирают пакет строго по OS и architecture
  из `RELEASE_MANIFEST.json`, сверяют его digest с `SHA256SUMS.txt` и проверяют
  контрольные суммы manifest и архива до распаковки.
- Unix-установщик без явного override всегда использует `$HOME/.local/bin`, а
  Windows-установщик — `%LOCALAPPDATA%\Programs\Puls\bin`.
- Unix-установщик извлекает из архива только ожидаемый обычный файл `puls`.
- Windows-установщик публикуется без BOM и с явной UTF-8 кодировкой, чтобы
  штатная команда `irm ... | iex` работала в Windows PowerShell 5 без искажения
  первой строки и русских сообщений.

## [0.1.1] - 2026-09-02

### Изменено

- Unix-установщик автоматически и идемпотентно настраивает `PATH` для Bash,
  Zsh, Fish и других POSIX-оболочек; удаление очищает только созданную Puls
  запись.
- Повторный запуск установщика явно обновляет существующий binary и не
  дублирует конфигурацию окружения.

## [0.1.0] - 2026-09-02

### Добавлено

- Измерение задержки, скорости скачивания и отдачи через Яндекс.Интернетометр.
- Измерение через speedtest.ru с выбором сервера и обновлением авторизации.
- Русскоязычный интерфейс со стандартным английским синтаксисом CLI.
- Структурированный JSON, частичные результаты и корректные коды завершения.
- Кроссплатформенные архивы для Linux, Windows и macOS.
- Автоматические проверки и выпуск релизов через GitHub Actions.
- Лицензия MIT.
- Новая публичная документация с быстрым стартом, примерами, расходом трафика и процедурой обновления протоколов.
- Репозиторные инструкции для AI-разработчиков.
- Прямая установка из GitHub Releases для Linux, macOS и Windows без отдельных package repositories.
- Проверяющие SHA-256 установщики `install.sh` и `install.ps1`.
- Штатное удаление через `install.sh --uninstall` и `install.ps1 -Uninstall`.
- Машиночитаемый `RELEASE_MANIFEST.json` с целями и SHA-256 релизных архивов.
- Самодостаточные release archives со всей публичной Markdown-документацией и checksummed installer assets.
- Документация архитектуры, поддержки и поведения участников.
- Автоматические release notes и provenance attestation релизных артефактов.
- Integration tests прямой установки и удаления на Linux, macOS и Windows.

### Изменено

- Усилена проверка discovery, HTTP-ответов и WebSocket-сообщений Яндекса и speedtest.ru.
- Обновлён общий движок измерений: корректная отмена, ранний отказ всех потоков, одно переподключение и освобождение goroutine.
- Релизный workflow теперь запускает форматирование, race detector, vet, staticcheck и govulncheck, готовит проверяемый draft и только затем публикует release.
- Release builder добавляет оба установщика в `SHA256SUMS.txt` и provenance attestation.
- Подробные инженерные документы перенесены из корня в каталог `docs`.
- Community-файлы GitHub перенесены в `.github`, исходники установщиков — в `scripts`.
- README сокращён до быстрого старта и основного контракта; дублирующие документы удалены.

### Исправлено

- Download учитывает полученные байты потоково после полной проверки HTTP-заголовков и сохраняет явную ошибку при повреждённом ответе.
- Сетевые ошибки не отображаются как успешные нулевые скорость или время измерения.
- Резервный список speedtest.ru используется только для ping; без JWT throughput возвращает явную ошибку авторизации.
